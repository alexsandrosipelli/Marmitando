Marmitando - Aplicativo de Delivery
Descrição: O Marmitando é um aplicativo de entrega de refeições que conecta usuários a restaurantes locais, facilitando o pedido de refeições prontas para entrega ou retirada. Este projeto foi desenvolvido como parte do curso de Sistemas Móveis Distribuídos do Senac.
